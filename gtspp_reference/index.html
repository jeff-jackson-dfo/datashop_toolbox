gtspp_stage1 / gtspp_stage2 / gtspp_odf_output — Reference

Status: Draft, generated from the in-code docstrings. Diátaxis quadrant: Reference — this document is information-oriented and describes the public interface of the GTSPP quality control modules as it exists in code. It is not a tutorial or a how-to guide, and it does not explain why the modules are built this way.

About this document

These three modules implement the Stage 1 and Stage 2 tests of the GTSPP Real-Time Quality Control Manual (IOC Manuals and Guides 22, first revised edition, 2010) for ODF files read with datashop_toolbox, and write the results back into the ODF files. This reference is organized like the toolbox's own: one subsection per Python module, listing a one-line summary, its classes with their methods, and its module-level functions. Signatures and descriptions come directly from the source and docstrings, so regenerate this document whenever the code changes. Private helpers (names beginning with an underscore) are listed because they affect how the classes behave.

Modules covered

Module Purpose
gtspp_stage1.py Stage 1 tests 1.1 to 1.6: platform, date/time, location, land, speed and sounding.
gtspp_stage2.py Stage 2 tests 2.1 to 2.12 on CTD profiles, plus flag inheritance for derived parameters.
gtspp_odf_output.py Writes flags, QCFF_01 and the QUALITY_HEADER into quality-controlled copies of the ODF files.

The three modules work side by side in any folder, or inside src/datashop_toolbox/.

Command-line entry points

Command Description
python gtspp_stage1.py FOLDER Run Stage 1 and write a CSV summary.
python gtspp_stage2.py FOLDER Run Stage 1 and Stage 2 and write CSV summaries and a list of flagged values.
python gtspp_odf_output.py FOLDER --out-dir OUT Run both stages and write quality-controlled ODF files to OUT.
